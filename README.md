## 產品介紹

工程協作管理平台是為工程、專案與跨部門團隊打造的數位工作平台。它把日常任務、專案時程、會議、請假與加班、人員資料及通知整合至同一個介面，降低分散使用試算表、通訊軟體與人工追蹤造成的資訊落差。

平台採模組化設計，可依不同公司的組織、角色、流程與品牌需求進行設定，也可串接既有的 Microsoft 365、LINE 與雲端資料服務。

## 核心價值

- **集中管理**：任務、人員、會議、行事曆與公告在同一平台完成。
- **即時掌握**：透過看板、矩陣、甘特圖與統計資訊掌握進度與風險。
- **降低漏接**：重要異動可透過 Teams、Outlook 或 LINE 發送通知。
- **彈性導入**：支援部門、角色、權限與通知流程客製化。
- **資料可攜**：行事曆與管理資料可依條件匯出為 Excel 或 CSV。

## 主要功能

| 功能模組 | 說明 |
| --- | --- |
| 首頁與公告 | 集中發布公告、設定置頂與有效期間 |
| 任務看板 | 管理待辦、進行中與已完成任務，支援多人指派、優先度與進度追蹤 |
| 艾森豪矩陣 | 依重要性與急迫性分流任務，協助安排執行順序 |
| 行事曆 | 整合專案、請假與加班行程，提供分頁篩選及 Excel／CSV 匯出 |
| 專案甘特圖 | 以時間軸呈現專案期間、里程碑與完成進度 |
| 效率統計 | 彙整完成率、逾期項目與工作狀態 |
| 會議管理 | 建立、修改與取消會議，管理與會者及會前提醒 |
| 請假與加班 | 建立申請、指定被通知者，並同步顯示於行事曆 |
| 人員管理 | 維護部門、職務、帳號與通知識別資料 |
| 權限管理 | 依角色限制人員維護、管理操作及系統診斷功能 |
| 多管道通知 | 支援 Microsoft Teams、Outlook 與 LINE Official Account |
| 人員同步 | 可與 Microsoft 365 組織帳號進行同步 |

## 適用情境

- 工程部門與專案團隊
- 設備、自動化、機電與維護單位
- 需要跨部門任務追蹤的中小企業
- 希望整合 Microsoft 365 通知的組織
- 目前以試算表管理、準備導入數位化流程的團隊

## 系統特色

### 可視化管理

透過任務看板、艾森豪矩陣、行事曆、甘特圖與統計頁面，讓管理者與執行人員使用不同視角掌握相同資料。

### 組織與權限

支援多層級部門、職務與角色權限。一般使用者只會看到工作所需資訊，管理與診斷功能由授權人員操作。

### 企業通知整合

任務、會議、公告、請假與加班等事件，可依導入方案連接 Teams、Outlook 或 LINE，減少人工轉發與遺漏。

### 客製化能力

可依客戶需求調整：

- 公司名稱、Logo、色彩與介面文案
- 部門、職務、角色與權限規則
- 表單欄位與簽核／通知流程
- 報表、統計指標與匯出格式
- 雲端部署、資料來源與第三方服務串接

## 技術與部署需求

本產品採 Python Web 架構，可部署於客戶指定的雲端環境或企業內部主機。實際需求會依使用人數、資料量、通知方式、資安政策及備援要求評估。

基本整合選項包含：

- 雲端或內部 Web 主機
- Google Workspace 資料服務
- Microsoft 365、Teams 與 Outlook
- LINE Official Account
- 排程、自動提醒與健康檢查

> 正式環境的帳號、憑證、Webhook 與連線資訊均須由部署端以安全設定管理，不包含於原始碼或公開文件中。

## 導入流程

1. **需求訪談**：確認組織、角色、功能、通知與報表需求。
2. **環境規劃**：選擇部署位置、資料服務與企業帳號整合方式。
3. **客製設定**：套用品牌、部門、權限及工作流程。
4. **測試驗收**：驗證資料、權限、通知、匯出與異常處理。
5. **教育上線**：提供操作說明並協助正式啟用。
6. **維護升級**：依合約提供問題處理、備份與版本更新。
