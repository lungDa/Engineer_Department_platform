# 不改動正式執行流程的第一批改善

本次僅新增 `.github/workflows/python-source-validation.yml` 與本說明，對應架構檢查第 10 項的基礎 CI。原有應用程式、套件、部署設定及排程內容均未改動。

## 檢查內容

- PR、main 提交及手動執行時，在 Python 3.11／3.12 分別檢查所有 Git 追蹤的 Python 檔案語法。
- 不安裝應用套件、不匯入或執行業務模組、不啟動 Streamlit／FastAPI。
- 不使用部署或業務服務 secrets，不連接 Google Sheets、Drive、LINE、Microsoft 365 或正式 API。
- 沒找到 Python 檔案也會失敗，避免空檢查誤報成功。
- 工作權限為 contents: read，逾時 5 分鐘；checkout 不保留 Git 憑證。

## 驗證界線

語法通過不代表登入、權限、通知或端到端整合通過。先前整合修改版的 55 個通過案例不屬於本 PR，也不作為本 PR 的驗證結果。

後續密碼雜湊、部門隔離、資料結構遷移與通知佇列仍須另行測試及分批導入。本批不切換那些行為。

本批是開發檢查工具，無須部署應用即可使用。PR 分支尚未變更正式 main；若外部託管平台對任何 main 提交自動重建，合併前仍須核對平台的建置篩選規則，不能以本次沒有部署步驟推論外部平台不會重建。
